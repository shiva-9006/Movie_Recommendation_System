# Movie Recommender System

A content-based movie recommender built with Python, scikit-learn, and Streamlit. The project uses cosine similarity over a combined movie metadata text field to recommend movies similar to the selected title.

## Features
- Cinematic Streamlit interface
- Movie picker with top-5 recommendations
- TMDb poster fetching
- Graceful fallback when the model files are not present
- Model generation script for local reproduction

## Project structure
- `app.py` – Streamlit frontend and recommendation logic
- `generate_model.py` – creates the `movie_list.pkl` and `similarity.pkl` files
- `model/` – folder for the pickled recommendation assets
- `requirements.txt` – Python dependencies

## Setup

1. Create and activate a virtual environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Generate the model files from the TMDb dataset:

```bash
python generate_model.py --movies-data /path/to/tmdb_5000_movies.csv --credits-data /path/to/tmdb_5000_credits.csv
```

4. Run the app:

```bash
streamlit run app.py
```

## Model format
The app expects the following files in the `model` folder:
- `movie_list.pkl`
- `similarity.pkl`

These files are generated by `generate_model.py` and loaded by `app.py` at startup.

## Notes
If the model files are missing, the app shows a clear setup message instead of crashing.
